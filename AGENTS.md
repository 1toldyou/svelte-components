# AGENTS.md — svelte-components

## Layout

- **Library source**: `my-svelte-components/src/lib/`
- **Library entry**: `my-svelte-components/src/lib/index.ts` — re-exports each component from its own directory
- **Component pattern**: Each component is a folder with `<Name>.svelte` + `index.ts` barrel export
- **Showcase app**: `my-svelte-components/src/routes/` (SvelteKit pages to preview components)
- **Stories**: `my-svelte-components/src/stories/` plus inline `*.stories.svelte` alongside source
- **All work** happens inside `my-svelte-components/`

## Commands (run from `my-svelte-components/`)

| Command | Purpose |
|---|---|
| `npm run dev` | Start SvelteKit dev server |
| `npm run check` | Type-check (`svelte-kit sync && svelte-check`) |
| `npm run package` | Build library to `dist/` (runs `svelte-package` + `publint`) |
| `npm run build` | Build showcase app + package library |
| `npm run storybook` | Start Storybook on `:6006` |

## Key Facts

- **Svelte 5** — codebase uses legacy reactive `$:` syntax, not runes yet
- **No test framework** is configured. Verify via `npm run check` (type-checking) and Storybook.
- **`engine-strict=true`** in `.npmrc` — `npm install` may fail on unsupported Node versions
- **`dist/` and `/.svelte-kit/`** are gitignored; `dist/` is the npm publish artifact
- **`tsconfig.json` extends `.svelte-kit/tsconfig.json`** (generated by `svelte-kit sync`)
- **Adapter**: `@sveltejs/adapter-static` for the showcase app
